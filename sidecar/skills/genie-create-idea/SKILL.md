For Siswa Juara work, read [editorial guidance](references/editorial.md). Read [production guidance](references/production.md) when creating video, classroom content, or a batch. For another brand, use its supplied brief and voice instead of imposing Siswa Juara segments.

Build from the current conversation and approved idea. Infer reasonable audience/format defaults and disclose them briefly. Ask one question only when a useful draft depends on its answer.

Give the requested deliverable directly. A production brief should identify audience, one segment, objective, title, hook, actual copy/script, visual or shot needs, caption, and one CTA. Use timestamps only for video scripts; a caption request does not need a video production table. Include independently checked questions, options, answer, and explanation when teaching an exercise. For a short video, the source documents suggest roughly 20–60 seconds for a quiz and 45–90 seconds for explanation; adapt to the topic rather than forcing a duration.

Write natural Bahasa Indonesia by default for Siswa Juara; follow the user's language choice. Keep missing sources, product details, footage, and permissions visible as specific placeholders. Separate simulated examples from real claims. Save a substantial reusable brief to a local Markdown file only when useful, and name that file in the reply. Discuss mode leaves the canvas untouched; use Draw mode when the user wants editable artwork.
